WHAT THIS PACKAGE DOES
- Locks Wrangler deployments to the existing Worker name: calm-forest-aed7
- Keeps the same workers.dev URL across future releases
- Prevents the random Worker-name problem
- Helps Supabase session persistence and Safari password recognition remain tied to one origin

FIRST-TIME COMPUTER SETUP
1. Install Node.js.
2. Open Terminal / Command Prompt in this folder.
3. Run:
   npm install
4. Authenticate Cloudflare:
   npx wrangler login
5. Deploy:
   npm run deploy

FUTURE UPGRADES
- Replace the app files in this same project folder with the newer Mana Movement release.
- Keep wrangler.jsonc unchanged.
- Run:
  npm run deploy
